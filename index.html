Project List:

Click project titles to read more about them!

  1. Inside Out 2 Lighting Study (Nuke, Katana, RenderMan)
    • Conducted a lighting study of a shot from Inside Out 2 within Pixar's technical pipeline, using a still from M. Butterfly as visual reference for mood, color, and emotional tone.
  2. Coco Fireworks FX Study (Houdini, Nuke, Katana, RenderMan)
    • Simulated and integrated procedural fireworks into a shot from Coco within Pixar's technical pipeline, focusing on timing, compositing, and visual continuity.
  3. Auto Lip Sync Blender Add-on (Python, Blender API, WhisperX, Phonemizer)
    • Developing a Blender add-on that automates first-pass lip sync generation using speech recognition and forced-alignment models.
    • Built tooling to convert phoneme timing data into automated facial animation keyframes for existing character animation workflows.
    • Implemented validation systems for incomplete viseme mappings and evaluated alignment approaches for timing accuracy, runtime performance, and animator usability.
    • Supports English language processing, CPU/GPU execution, and both 15- and 22-viseme mapping systems.
  4. Gaspard et Lisa, Friends Forever (Blender)
    • Recreated Georg Hallensleben's painterly illustration style using Blender Brushstroke Tools for Anne Gutman's characters, Gaspard and Lisa.
    • Adapted brushstroke-card workflows typically used for environments onto deforming rigged characters.
    • Designed a cage-based deformation system that preserved texture integrity and hand-painted visual quality during character animation.
  5. UPSTREAM (Blender)
    • Collaborated with fellow Technical Director interns at Pixar on an animated short film, contributing to animation and developing a facial rigging system that automated texture switching, improving workflow efficiency and reducing production time.
  6. Doll in a Glass Cup (Maya, Flow, Substance Painter, Katana, RenderMan)
    • Modeled, shaded, and lit an antique doll and glass teacup within Pixar's technical pipeline, ensuring accurate material properties and final render quality.
  7. Cat Sketcher (Houdini, VEX, Blender)
    • Developed a procedural animation and workflow for animating characters drawing using Houdini's VEX and Blender.
  8. Chromatic Aberration Shader (C/C++, OpenGL, GLSL)
    • Wrote a chromatic aberration shader with sliders that control individual indices of refraction for R, G, B, allowing for various effects. Referenced this implementation.
  9. Random Cobweb Generator (C/C++, OpenGL)
    • Developed a procedural cobweb generator in C++ and OpenGL inspired by DreamWorks' 2011 paper, "Building and Animating Cobwebs for Antique Sets."
